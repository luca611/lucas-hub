# Luca's Hub

A space-themed portfolio showcasing my games, web projects and jobs.
Visit it at [luca611.github.io/lucas-hub](https://luca611.github.io/lucas-hub).

## Structure

- `index.html` – page markup
- `styles.css` – styling (shares its look with [my personal site](https://luca611.github.io/PersonalSite/))
- `assets/` – fonts and space artwork
- `projects/` – project preview screenshots

## Run locally

No build step. Open `index.html` in a browser.

## Contributing

This is a personal showcase, so contributions aren't accepted, but feedback is welcome.
